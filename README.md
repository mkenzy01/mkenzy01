## Selected Projects

### [TripLens Countries Explorer](https://github.com/mkenzy01/triplens-countries-pipeline)

An ELT pipeline for collecting and preparing country data for analytics. It extracts paginated API data, stores raw and transformed records in MinIO, loads structured data into Snowflake and uses Airflow and dbt for orchestration and modelling.

`Python` `Apache Airflow` `MinIO` `Snowflake` `dbt`

### [MarketPulse Real-Time Pipeline](https://github.com/mkenzy01/marketpulse-realtime-pipeline)

A streaming pipeline that ingests stock-market data through Kafka, processes events with PySpark Structured Streaming and stores the results in PostgreSQL for analysis in Power BI.

`Python` `Apache Kafka` `PySpark` `PostgreSQL` `Docker` `Power BI`

### [CivicPulse 311](https://github.com/mkenzy01/civic-urban-end-to-end-de-pipeline)

An end-to-end pipeline for NYC 311 service-request data. It combines Python extraction and transformation with Azure Blob Storage, Azure Data Factory, PostgreSQL and Airflow-based workflow orchestration.

`Python` `Apache Airflow` `Azure` `PostgreSQL` `Terraform` `Power BI`

### [OpenSky on Microsoft Fabric](https://github.com/mkenzy01/opensky-fabric)

A real-time aviation-data project that publishes OpenSky flight events to Microsoft Fabric, routes them through Eventstream and analyses them in Eventhouse using KQL and Power BI.

`Python` `Microsoft Fabric` `Eventstream` `Eventhouse` `KQL` `Power BI`

### [E-commerce Semantic Search Pipeline](https://github.com/mkenzy01/building-an-ecommerce-semantic-search-pipeline)

A medallion-style pipeline for transforming unstructured e-commerce review data with PySpark and preparing enriched records and embeddings for semantic search.

`Python` `PySpark` `Medallion Architecture` `Semantic Search`

### [CoffeeClub Data Migration](https://github.com/mkenzy01/coffeclub-data-migration-DB)

A Python and PostgreSQL project covering data migration, relational schema design, data validation and analytical SQL reporting.

`Python` `PostgreSQL` `SQL` `Data Modelling`
